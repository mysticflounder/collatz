# Collatz

Two self-contained research projects on the 3n+1 problem.

## [`ghost-cycles/`](./ghost-cycles)

Computational code accompanying the paper *Ghost Cycles of the Syracuse Map:
2-Adic Periodic Orbits and the Exceptional Set* (McKenna, March 2026,
[DOI 10.5281/zenodo.18949342](https://doi.org/10.5281/zenodo.18949342)).
Python analysis, Lean formalization of the cycle results, paper sources.

## [`collatz-conjecture/`](./collatz-conjecture)

Live Lean proof effort targeting the full Collatz conjecture, with a
machine-readable proof blueprint in `data/blueprint.db` and Lean source in
`lean/CollatzConjecture/`. The dashboard at
[proofprojects.org](https://proofprojects.org) reads this directory.
